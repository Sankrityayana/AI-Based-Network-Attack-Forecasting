# AI-Based Network Attack Forecasting

A university-level machine learning project that learns temporal patterns
in network traffic and forecasts the probability of malicious activity
in future traffic windows.

## Project Status

🚧 Under Development

## Objectives

- Process network traffic data
- Create temporal network states
- Train an LSTM forecasting model
- Compare against Logistic Regression
- Evaluate forecasting performance
- Build an offline Streamlit demonstration

## Technology Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- TensorFlow/Keras
- Matplotlib
- Streamlit

## Dataset

CIC-IDS2017/2018 will be used as the primary dataset.

## Project Scope

This is a university-level research prototype and is not intended
as a production intrusion detection or automated cybersecurity system.
