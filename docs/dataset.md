# CIC-IDS2017 Dataset

## Dataset
CIC-IDS2017

## Source
Canadian Institute for Cybersecurity, University of New Brunswick.

## Purpose
The dataset will be used to train and evaluate the network attack
forecasting model.

## Data Type
Network flow records represented as CSV files.

## Planned Use
1. Dataset exploration
2. Feature selection
3. Data preprocessing
4. Temporal window creation
5. LSTM forecasting
6. Model evaluation

## Raw Data Location

data/raw/CIC-IDS2017/

## Important

Raw dataset files are not committed to the Git repository.
